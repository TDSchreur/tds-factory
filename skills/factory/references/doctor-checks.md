# Doctor checks

The report has `checks`, the shared checks, and `agents`, one entry per Agent target with its own `checks`. With `--agent` it holds only your entry. The shared checks are the CLI version, the tracker setup (`docs/agents/issue-tracker.md`, `docs/agents/domain.md` and an `## Agent skills` section in `AGENTS.md` or `CLAUDE.md`), the Git `origin` and its default branch, the Verify command and the optional Verify-fast command, `scratch-ignore` (for a Local tracker, whether git ignores `.scratch/`) and `guides` (every instruction guide `AGENTS.md` links to exists and has a valid `applyTo`). Your entry's checks are `binary`, `skills` (the required Skills), `config` (the optional `.factory/config.json`; a bad setting fails with its line) and `review` (the review capabilities).
