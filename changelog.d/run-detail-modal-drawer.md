### Changed

- The Dashboard opens the Run detail as a modal drawer on the right over a full-width board, with a light backdrop. Escape, a click on the backdrop and the close button close it and return focus to the card. Through 1024 CSS pixels it stays a full-screen sheet with Back.
- The Dashboard fits every width without a horizontal scrollbar: the board columns shrink to 9rem, the token usage table fills its panel and stacks each row on a narrow panel, and long titles and links wrap. Markdown tables in summaries keep their own scroll area.
