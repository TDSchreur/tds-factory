### Changed

- The Dashboard labels a local Spec or Ticket with its title, the first level 1 heading of the document, instead of its file name: "Spec: <title>" and "Ticket: <title>" in the Run detail, and the title on the Ticket tiles. A file name that starts with digits and a `-` keeps its number in front. The full path stays the tooltip; a document without a heading or not on disk keeps its file name, and GitHub and Azure DevOps links keep their labels.
