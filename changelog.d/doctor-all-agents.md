### Changed
- `tds-factory doctor` reports Claude, Codex and Copilot by default. The shared checks are reported once and each agent gets its own `binary`, `skills`, `config` and `review` checks. The report fails only when a shared check fails or no agent is usable. `--agent` with one agent still reports only that agent. In the JSON report, `checks` now holds only the shared checks and `agents` holds the per-agent checks.
