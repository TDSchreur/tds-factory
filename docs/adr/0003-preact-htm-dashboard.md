# Dashboard in Preact and htm, vendored, no build step

The Dashboard outgrew hand-written DOM code: every poll rebuilt the board, and keeping focus, scroll and open cards needed extra code. We rewrote it with Preact and htm, committed as ES modules in `dashboard/vendor/` and loaded through an import map, so the Factory still has no bundler and no runtime dependencies. We chose Preact over React and Vue for its size (about 15 KB for all three files) and because htm gives JSX-like templates without a compiler. The cost is that the vendored files are updated by hand, and the server's allow-list of served files grows with each module. We keep these files out of the top-level `vendor/` folder because that folder holds the skill submodules read by `sync`.
