# The Doctor reports every Agent target and needs one usable

The Doctor checked one Agent target, Claude by default, so a user of Codex or Copilot learned nothing unless they named it. [Issue #273](https://github.com/TDSchreur/tds-factory/issues/273) makes the default report all three. A machine rarely has all three agents, so an uninstalled agent must not fail the report; a user needs at least one.

The report has two parts. `checks` holds the shared checks (`cli`, `tracker`, `git`, `verify-command`, the optional `verify-fast` and `guides`, both added later) once. `agents` has an entry per Agent target, in the order claude, codex, copilot: `{ id, usable, checks }`, where `checks` are `binary`, `skills`, `config` and `review`. `binary` is `pass` when the agent's command is found on PATH and `missing` otherwise, never `fail`. An agent is a **usable agent** when all of its checks pass. Without `--agent`, `ok` is true when every shared check passes and at least one agent is usable; other agents show their lines in the report without changing `ok` or the exit status. When none is usable the report adds a top-level failing line telling the user to install an agent and run `tds-factory install`.

With `--agent X` the report holds only X and `ok` needs X's `skills`, `config` and `review` to pass. The `binary` check is shown but does not count, because the factory Skill runs the Doctor from inside that agent and the agent may not be on PATH under its command name (for example Copilot started from an IDE). This keeps the Preflight as strict as before. An entry can therefore read `usable: false` (its command is missing) while `ok` is true.

We considered a flat `checks` list with an `agent` field on each check. It keeps the old shape closer, but it hides which lines belong to which agent and makes the "usable" rule harder to read. The cost of the chosen shape is that the JSON report changes: a consumer that read every check from `checks` must now also read `agents[].checks`. The factory Skill is the only consumer in this repository and is updated with this change. Install scripts only print the report.
