# Run detail as a modal right drawer over a full-width board

Opening the Run detail as a non-modal drawer that pushed the board made the columns jump and squeezed the board into a horizontal scrollbar. The Run detail is now a native modal dialog styled as a sheet on the right (about 56rem wide, full height) with a light backdrop, so the board keeps its full width and stays visible behind it. Through 1024 CSS pixels it stays a full-screen sheet with Back navigation (ADR 0008). The browser provides the focus containment, inert background and Escape handling that were hand-written before. We rejected keeping the push layout with a smaller board, and a centered modal that hides the board. The cost is that another card cannot be selected until the detail is closed, and the board is not interactive while a Run is open. The page behind the drawer is not scroll-locked; the backdrop and `overscroll-behavior: contain` on the drawer keep scrolling contained.
