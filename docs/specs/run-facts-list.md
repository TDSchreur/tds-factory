# The Run facts are a list with icons and colours

Fast track. On the Dashboard, the facts of a Run (track, Tickets, Check verdicts, Check loops) were pills of one shape, so a user could not see which fact was which. They become a list with one row per fact: an icon, a label and a value. The track and Tickets rows have a blue accent, pass is green with a ✓, fail is red with a ✗, skipped is grey with a ⊘, and the Check loops row has the ↻ icon and the neutral colour. The icon and the colour carry the same meaning, so no fact depends on colour alone. The icon is hidden from screen readers, which read the label and the value. The hover text of each row stays. The same list is used on the card and in Run detail. A unit test pins what `chipsOf` returns for each fact (icon, label, value, class, plain reading and hover text), and the existing browser tests pin the rendered rows, the loop limit after an extra loop and the one-line height of each row. Out of scope: a colour for Check loops near the limit, and a logo image.
