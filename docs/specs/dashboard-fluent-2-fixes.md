# Dashboard: Fluent 2 follow-up fixes

The Check of the Fluent 2 restyle ([spec](dashboard-fluent-2.md)) left four small findings open in the Dashboard stylesheet, and this fix closes them. Diagnosis: (1) an abandoned card is dimmed with `opacity: .7`, which blends its text with the page and falls below the 4.5:1 contrast the Spec promises, and the contrast test samples no abandoned card; the card is drawn with token colours instead (the Background3 surface, a dashed border, no elevation), whose text pairs the tests already measure. (2) The forced-colours block restyles the primary, danger and pressed buttons only in their rest state, so their `:hover` and `:active` rules put a literal blue behind system-colour text; the block also covers those two states. (3) `border-style: double` on a waiting card is drawn solid at 2 px, so a forced-colours user sees no second line; the border is 3 px (thick plus thin stroke) so that it renders as two lines. (4) `.card:hover` and `.card.selected` set `box-shadow`, which removes the inner focus ring of `:focus-visible`; a focused card keeps its inner ring when it is hovered or selected. Tests fail on the old stylesheet: an abandoned Run in the contrast sampler, hover and active colours and a 3 px double border in the forced-colours test, and a focus test for a selected card.
