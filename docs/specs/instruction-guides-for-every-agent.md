# Route the instruction guides to every agent

The repository keeps eight Copilot instruction files in `.github/instructions/*.instructions.md`, each scoped with `applyTo`, but `AGENTS.md` does not link to them and there is no `.claude/rules/` folder. Only Copilot reads them: Claude Code never loads them, Codex never sees them, and the Factory's `run guides` and its Standards and Security reviewers never receive them, because the Factory takes its guides from the links in `AGENTS.md`. Fix, following the setup `docs/usage.md` already describes: `AGENTS.md` gets an "Instruction guides" section that links every `.github/instructions/*.instructions.md` file with one line saying what it covers (Codex reads `AGENTS.md`, and the Factory then scopes each guide by its `applyTo`); `tds-factory rules` writes the `.claude/rules/` copies with `paths:`, and they are committed so Claude Code loads each one for the files it covers; a test fails when a file in `.github/instructions/` is not linked from `AGENTS.md`, or when its `.claude/rules/` copy is missing or differs from what `tds-factory rules` would write. Documents: `AGENTS.md`, `docs/development.md` (where it describes the guides and how to change one: edit the `.github` file, then run `tds-factory rules`), and a changelog fragment is not needed because nothing users install changes. Out of scope: changing the guides' content, and making the Factory discover `.github/instructions/` without links.
