# Fix the Run detail drawer items left open in PR #468

PR #468 made the Run detail a modal right drawer (ADR 0031) and left four small items open, which this change closes. A text selection that starts inside the drawer and is released on the backdrop no longer closes the drawer: the backdrop closes it only when the pointer was both pressed and released on the backdrop, and a browser test covers both the drag and a plain backdrop click. The no-horizontal-scroll browser test also checks the drawer itself (`#detail`, which clips with `overflow-x: hidden`), so content clipped inside the drawer fails it. ADR 0031 states that the page behind the drawer is not scroll-locked, and that the backdrop and `overscroll-behavior` keep scrolling contained. The specs `dashboard-detail-modal-drawer.md` and `dashboard-responsive-usability.md` call the Run detail a drawer rather than a panel, the glossary's Avoid term, and the latter points to ADR 0031 instead of saying ADR 0008 refines the side drawer. The Help dialog's "help panel" wording and the released CHANGELOG stay as they are. A changelog fragment records the drag-select fix. Testing: the Verify command, `npm run check` and `npm run test:browser` pass.
