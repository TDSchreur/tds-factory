# Forget an unavailable install destination

A saved Claude destination that no longer exists currently blocks every selection that omits it: both installation and selection persistence explicitly reject dropping it, even when it was a temporary directory. Allow an explicitly deselected unavailable destination to be forgotten, warn that Factory files may remain if it returns, and install and save the requested destinations; preserve cleanup and backups for available destinations, and do not recreate the missing destination. Cover the real install and selection paths with regression tests, including available cleanup and retained destinations. Documents: `docs/usage.md`, `docs/specs/install-destination-selection-integration.md`, and CLI help where applicable. Estimate: one Ticket plus Define artifacts, about 6 files and 8 KB of diff.
