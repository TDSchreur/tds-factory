# Reliable tests: close the left-open items

The first reliable-tests Run (`docs/specs/reliable-tests.md`) left a few findings open. This Run closes them. The remaining fixed-sleep poll loops in `test/dashboard-actions.test.js` and `test/browser.js` (the driver start-up poll and `waitFor`) wait with `waitUntil` from `test/wait-until.js`. The `waitUntil` "checks once more at the deadline" test scripts `Date.now` instead of racing the real clock. The guide, the `reliable-tests` Skill and `docs/development.md` all say to repeat a test 30 times, and the first Spec no longer names `--test-isolation=process`, which `scripts/repeat-changed-tests.js` does not use. The `stopDriver` wait in `test/browser.js` keeps its loop: it waits for a process to exit within a time limit and returns a boolean instead of failing. No new public interface, schema or dependency. The two assertion nits in `dashboard-projects` and `dashboard-pr-status` are not part of this Run.
