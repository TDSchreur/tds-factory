# Give Check reviewers the diff and file list inline

[GitHub issue #286](https://github.com/TDSchreur/tds-factory/issues/286), Fast track (the user left the track choice to the coordinator for this session and prefers the Fast track in doubt), priority work of milestone v0.6.0. The Check reviewers are read-only and cannot run `git`, so each of the three rediscovers the change by reading files: 15 to 32 tool calls and about 110k tokens per reviewer per pass, and a pass for a three-line change still cost about 47k. Once per Check pass the coordinator collects the diff against the base, the changed file list and the Verify summary, and passes them inline in each reviewer's assignment; reviewers start from that diff and open other files only to follow a reference. For a large diff the coordinator passes the file list and the per-file diffs up to a size limit (about 40 KB in total) and says where the rest is, so the reviewer reads those files itself. The Check section of `skills/factory/SKILL.md` and the `factory-check` and `factory-interactive-check` agents of the three targets say so, tests pin the text, and the PR records this Run's own reviewer tool calls and tokens against the before numbers. Out of scope: the term sweep command (#287), smaller re-review after a Rework (#289), changing the reviewers' tools or independence.
