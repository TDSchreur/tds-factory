# Azure DevOps: the merge strategy policy is not a check

On a Project hosted in Azure DevOps, the Dashboard shows "Checks: failing: Require a merge strategy" in red on a pull request that has nothing wrong with it. Recorded in the sandbox repository `Kahoot`, the "Require a merge strategy" branch policy (type id `fa4e907d-c16b-4a4c-9dfa-4916e5d171ab`, the same in every organisation) is `rejected` while the PR has no allowed merge strategy selected, empty or disallowed `completionOptions` alike, and `approved` as soon as an allowed one is selected; the code has no part in it, and the completion dialog offers only the allowed strategies. It is a completion setting, not a check, but `parseStatus` in `src/pr-azure.js` counts every blocking policy other than a reviewer policy as a check. `parseStatus` leaves the merge strategy policy out of the checks, matched by its type id because the display name is localised; a PR with only that policy reports no checks. The test seam is `parseStatus`, with the recorded fixture `merge-strategy` in `test/fixtures/pr-status/azure/` and a regression test in `test/pr-azure.test.js`.
