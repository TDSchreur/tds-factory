# Compact agent instructions

An agent that edits a workflow loads the whole GitHub Actions instruction guide (54 KB, about 13k tokens) because its `applyTo` glob matches, although most of it is generic advice (deployment strategies, load testing, observability) that this repository does not use. The Factory Skill also repeats, in its Preflight and Check sections, detail that its reference files already hold. This Run shrinks the GitHub Actions guide to about 8 KB that keeps the rules which matter (SHA pinning, least-privilege permissions, script injection, OIDC, caching, tests, deployment, a review checklist and troubleshooting), regenerates its `.claude/rules` copy with `tds-factory rules`, and condenses the Preflight check exceptions and the Check "In short" paragraph in `skills/factory/SKILL.md`, keeping every phrase that `test/skills.test.js` and `scripts/doc-checks.js` pin. Documents: `.github/instructions/github-actions-ci-cd-best-practices.instructions.md`, `.claude/rules/github-actions-ci-cd-best-practices.md`, `skills/factory/SKILL.md` and a changelog fragment; the Sweep for the guide's name finds no other document to update.
