# The Run id is found after an escaped line break, and small token usage items are closed

Fast track. Diagnosis: a session log is matched to a Run when it names the Run id as a whole word (ADR 0026). In the raw text of a JSON log, a line break inside a string is a backslash followed by `n`, `t` or `r`, and the letter counted as part of the id, so an id at the start of a line was rejected and a session whose only mention sat there was undercounted. The match now accepts a backslash-escaped `n`, `t` or `r` before the id, and keeps rejecting a longer id (`<id>-2`) and a letter directly before the id. Three small items from the token usage and stale-document Runs are closed with it: the usage guide and the glossary say "Build wrap-up" and "of which reasoning" where they describe the table, a browser test shows that the Ticket tile breakdown opens on a real mouse hover as well as on focus, and a paragraph of the Factory skill's main file moves to a reference so the file has room under its 18,000 byte limit.
