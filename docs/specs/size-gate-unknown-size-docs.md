# Document the unknown size warning of the size gate

Leftover of [#532](https://github.com/TDSchreur/tds-factory/issues/532) (Check 1, Left open), Fast track. `run transition --to check` prints "the Run size is unknown (git timed out or its output was too large), counted as over the limit" when the size cannot be measured and the user has not accepted the size. The transition bullet in `skills/factory/references/progress-commands.md` and the Transition bullet in [run-size-gate.md](run-size-gate.md) do not mention it, and the changelog has no line for it. This change adds the sentence to both, adds a changelog fragment, and deletes the boilerplate sentence "Follow-up after Finish keeps its PR feedback scope apart from this Spec." with its empty Further Notes heading from [run-size-gate-leftovers.md](run-size-gate-leftovers.md). No code changes.
