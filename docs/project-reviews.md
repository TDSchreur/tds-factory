# Project review guide

Projects can add required source, UI and UX reviews to the Factory's Check Stage. Ask your coding agent to use the shipped `add-project-review` Skill to set them up.

The complete [configuration and authoring guide](../skills/add-project-review/references/project-reviews.md) covers the schema, Angular and UX examples, review reports, browser setup, frozen Run snapshots and troubleshooting. It is also bundled with the installed Skill for projects outside this repository.
